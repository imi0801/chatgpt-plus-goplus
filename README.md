## 常见问题

### ChatGPT Plus 国内可以直接付款吗？

有些海外信用卡可以直接订阅，但国内银行卡经常受支付地区、账单地址和风控影响。没有稳定海外支付方式时，可以考虑卡密充值。

### ChatGPT 官方支持微信或支付宝吗？

OpenAI 官方订阅页通常不直接支持国内微信或支付宝。这里介绍的是通过卡密方式完成充值。

### 充值需要提供 ChatGPT 密码吗？

不需要把账号密码交给别人。你只需要自己登录 ChatGPT，复制 Session，并在确认页核对账号。

### Session 是什么？

Session 用来识别当前浏览器登录的 ChatGPT 账号。复制前必须确认浏览器里是目标账号，否则可能对应到其他账号。

### Session 复制后要注意什么？

按页面提示粘贴到充值页面即可。充值完成后，也可以重新登录账号来刷新会话状态。

### 卡密验证不通过怎么办？

先检查是否复制完整，尤其是前后空格和换行。如果仍然无法验证，保留订单号和付款记录联系平台售后。

### 充值后没有看到 Plus 怎么办？

先刷新 ChatGPT 网页，再退出重新登录。移动端、客户端或相关工具可能有同步延迟，可以等待几分钟后再看。

### Plus 和 Pro 应该怎么选？

第一次开通建议优先考虑 Plus，适合多数写作、学习、办公和轻量编程场景。Pro 更适合每天高频使用、需要更高额度的用户。

### 会不会充错账号？

容易出错的地方主要是浏览器登录状态混乱。充值前退出无关账号，复制 Session 前确认邮箱，确认页再检查一次，可以明显降低误充概率。

### 订单信息要保存多久？

建议至少保存到会员状态确认生效后。订单号、卡密、付款记录和页面截图都能帮助售后快速定位问题。
