## 1. 30 秒选路线：按你手里有什么来选

| 你的情况 | 选哪条 | 为什么 |
|---|---|---|
| 有 Visa / Mastercard 等**海外发行**的信用卡 | 路线 A：官网 | 价格最低，自动续费，账单在 OpenAI 名下 |
| 有 iPhone，并且已经有一个美区等海外 Apple ID | 路线 B：App Store | 用礼品卡余额付款，不需要信用卡 |
| 只有国内银行卡、国区 Apple ID | 路线 C：支付宝 / 微信 | 人民币付款，开到自己账号上，不需要准备任何海外资源 |

> [!TIP]
> 订阅绑定的是**账号**，不是设备。在电脑上开通，手机 App 登录同一个账号就是 Plus，反过来也一样。所以不用纠结「在哪台设备上开」，只要选对付款路线。

## 2. 开通前准备：账号、网络、套餐

开通 Plus 卡住的人，大部分不是卡在付款，而是下面三件事没准备好。

### 2.1 一个能正常登录的 ChatGPT 账号

打开 chatgpt.com，能进入对话页、左下角显示你的邮箱，就算准备好了。还没有账号的，用 QQ 邮箱、163 邮箱这类国内邮箱就能正常注册，已有 Gmail 的也可以直接用 Google 登录。三种方式注册的账号开 Plus 没有任何区别。完整步骤见 [ChatGPT 账号注册](register/)。

有一种账号要先处理：**加入过 Team 或 Business 工作区的账号**。这类账号登录后默认进的是工作区，个人订阅开不上去。开通前先在设置里退出工作区，切回个人空间。

### 2.2 一个稳定的网络

标准不是「能打开首页」，而是能正常发一条消息并收到回复。网络时断时续时，最常见的后果是付完款页面状态刷不出来，看起来像没开通。

### 2.3 先想清楚开哪一档

| 套餐 | 适合谁 | 一句话判断 |
|---|---|---|
| 免费版 | 偶尔问问题、试用 | 用着不卡额度，就没必要升级 |
| Plus | 每天用于工作、学习、写作，或轻度用 Codex 写代码 | 绝大多数个人用户的选择 |
| Pro 100 | 每天大量用 Codex 编程，Plus 额度经常用完 | 用量约为 Plus 的 5 倍档位 |
| Pro 200 | 全天高强度开发、长时间任务 | Pro 100 也经常用完再考虑 |

各档具体的模型和额度以 OpenAI 账号内实际显示为准，官方会不定期调整。第一次开通建议从 Plus 开始，用一个月看额度够不够，不够再升，升级不需要等到期。Pro 的完整说明见 [ChatGPT Pro 怎么开通](pro/)。

## 3. 路线 A：官网海外信用卡开通

这是 OpenAI 自己的收款通道，Plus 官方价是 **$20 / 月**，部分地区结账时另加税。

### 操作步骤

1. 电脑浏览器登录 chatgpt.com，点左下角头像，选「升级套餐」。
2. 在套餐页选 Plus，点「升级到 Plus」，进入 Stripe 结账页。
3. 填写卡号、有效期、CVC，**账单地址填写与发卡行登记一致的地址**。
4. 提交付款。如果银行要求 3DS 验证，在弹出的页面或银行 App 里确认。
5. 付款成功后自动跳回 ChatGPT，刷新页面即可看到 Plus。

### 最常见的 4 种失败

| 提示或现象 | 原因 | 怎么办 |
|---|---|---|
| Your card was declined | 卡是国内发行的，或银行风控拦截了境外交易 | 换海外发行的卡；国内双币卡成功率很低，不建议反复尝试 |
| 账单地址校验失败 | 填的地址和发卡行登记的对不上 | 按银行账单上的地址原样填写 |
| 3DS 验证弹窗打不开或超时 | 网络或浏览器插件拦截 | 关掉广告拦截插件，换无痕窗口重试 |
| 页面没有「升级」按钮 | 账号或网络所在地区不在支持范围 | 换路线，不用在这里耗着 |

> [!WARNING]
> 同一张卡短时间内连续失败多次，可能被风控判定为可疑交易，之后连能用的卡也会被拒。失败两次就停下来排查，不要连刷。

虚拟信用卡（U 卡、预付卡）这条路，2026 年成功率已经很不稳定，而且开卡往往要先买 USDT，流程长、风险大，这里不推荐。

## 4. 路线 B：iPhone App Store 内购开通

iOS 版 ChatGPT App 里的 Plus 内购价格是 **$19.99 / 月**，按 Apple ID 所在地区计税，扣的是 Apple ID 余额。

### 操作步骤

1. 准备一个美区（或其他已支持地区）的 Apple ID。国区 Apple ID 在 App 里看不到升级入口。
2. 用该地区的 Apple 礼品卡给 Apple ID 充值余额，金额要够一个月的订阅费加税。
3. 在 App Store 登录这个 Apple ID，下载 ChatGPT 官方 App。
4. 打开 App，登录你的 ChatGPT 账号，点「升级到 Plus」，用 Apple ID 余额付款。
5. 付款完成后，网页版和其他设备登录同一账号也会显示 Plus。

### 要特别注意的 3 点

- **礼品卡来源。** 来路不明的低价礼品卡可能是盗刷卡，兑换后 Apple ID 会被冻结，余额和订阅一起失效。只在正规渠道购买。
- **改 Apple ID 地区有门槛。** 把现有 Apple ID 改成美区，需要先用完余额、取消现有订阅。更省事的做法是单独注册一个美区 Apple ID，只在 App Store 里登录，不要登录 iCloud。
- **退订要在 Apple 那边操作。** App Store 内购的订阅由 Apple 管理，取消和退款都要在 iPhone 的「设置 → Apple ID → 订阅」里处理，在 ChatGPT 网页上操作不了。

iPhone 上不想折腾 Apple ID 的，可以直接用 Safari 打开第 5 节的路线，详见 [iPhone 怎么开通 ChatGPT Plus](iphone/)。

## 6. 会话信息是什么，交出去安全吗

第三方开通都需要你提供第 2 步里那段「会话信息」，这是很多人犹豫的地方。把它讲清楚：

- **它是什么。** 你登录 ChatGPT 后，浏览器里保存着一个登录凭证，证明「这个浏览器已经登录了这个账号」。`/api/auth/session` 页面显示的就是这个凭证，外加邮箱、套餐等基本信息。
- **它不是什么。** 它不包含你的密码，拿到它的人无法改你的密码或绑定的邮箱，也无法看到你的银行卡。
- **它能做什么。** 在有效期内，持有它的人可以以你的身份访问账号，包括给账号开通订阅。正因为能开通，平台才需要它；也正因为有这个能力，**只交给可信的平台**。
- **用完怎么收回。** 开通完成后，如果你不放心，可以在 ChatGPT「设置 → 安全」里选择退出所有设备。这会让之前所有的登录凭证失效，你重新登录即可，已开通的 Plus 不受影响。

> [!CAUTION]
> 任何要你提供 ChatGPT **密码**、邮箱验证码，或者要你登录他们给的账号的渠道，都不要用。正规的开通只需要会话信息，订阅开在你自己的账号上。

## 7. 怎么挑第三方平台：5 条硬标准

第三方开通的风险不在于「第三方」本身，而在于挑错了平台。下单前逐条核对：

1. **不要密码。** 只要会话信息，不要账号密码和验证码。
2. **先校验，后付款。** 粘贴会话信息后能显示你的邮箱和当前套餐，确认无误再付款。先收钱再问你要账号的，出了问题很难说清。
3. **开在你自己的账号上。** 不是给你一个现成账号，也不是拉你进某个工作区。
4. **失败原路退款，订单可查。** 有订单号、有状态页、有明确的退款规则。
5. **价格不能离谱地低。** 官方价 $20 / 月，按汇率折算加上通道成本，人民币价格低于官方成本太多的，往往是共享号、黑卡或短期内会掉的会员。

> [!WARNING]
> 淘宝、闲鱼上几十块一个月的「Plus 共享号」「合租车位」，本质是多人共用一个账号。对话记录互相可见，额度被别人分走，账号随时可能因异常登录被风控。想要稳定使用，不要碰。

## 8. 开通后怎么确认 Plus 已经生效

开通完成的标志不是「页面提示成功」，而是你自己账号里这三处都对上：

1. **左下角账号菜单**显示 Plus 标识，不再出现「升级到 Plus」的按钮。
2. **设置 → 账单**里显示 Plus 以及到期日期。
3. **模型选择器**里能选到 Plus 档的模型，正常使用不再频繁弹出额度提示。

网页端通常最先更新，手机 App 和桌面客户端可能慢几分钟。App 里不显示，先完全退出 App 再打开，或者退出登录重进。用 Codex 的，在 Codex App 或 CLI 里重新登录一次，额度会按新套餐刷新。

> [!TIP]
> 第三方开通后，账单页可能显示「套餐已取消，将不再续订」。这是**正常的**：这种方式开的会员不会从任何卡上自动扣款，到期前回来再充一次即可。

## 9. 到期、续费和升级 Pro

三条路线的续费逻辑不一样，弄混了容易多花钱。

| | 官网信用卡 | App Store 内购 | 支付宝 / 微信第三方 |
|---|---|---|---|
| 到期后 | 自动扣款续订 | Apple 自动续订 | 到期即止，不扣款 |
| 怎么停 | 设置 → 账单 → 取消订阅 | iPhone 设置 → Apple ID → 订阅 | 不续即可 |
| 能否一次买多个月 | 按月扣 | 按月扣 | 不能，见下方说明 |

**不要一次下多单。** ChatGPT 官方没有多月套餐，同一个账号连续充两次，第二次会**覆盖**第一次，时长不会叠加，实际只生效一个周期。正确做法是到期前 1 到 2 天再续。

**换渠道前先关掉自动续订。** 以前在官网或 App Store 订阅过、现在改用第三方的，先确认原来的自动续订已经取消，否则两边都可能扣费。

**Plus 升级 Pro 不用等到期。** 已经是 Plus 的账号可以直接开 Pro，新套餐会覆盖现有的 Plus，从开通当天起按 Pro 计算周期。Plus 额度经常用完、又在大量用 Codex 写代码的，可以考虑。

## 10. 分阶段排查：卡在哪一步看哪一段

### 阶段一：还没到付款，就卡住了

| 现象 | 原因 | 处理 |
|---|---|---|
| chatgpt.com 一直转圈或打不开 | 网络不稳定 | 换稳定的网络环境再操作 |
| 官网没有「升级」按钮，或提示 not available in your country | 账号或网络所在地区不在支持范围 | 换路线 C |
| iPhone App 里找不到升级入口 | Apple ID 是国区 | 换美区 Apple ID，或用 Safari 走路线 C |
| `api/auth/session` 页面显示空白或 `{}` | 这个浏览器没登录，或登录已过期 | 先在同一浏览器正常登录 chatgpt.com，再打开 |

### 阶段二：进了付款环节，但付不进去

| 现象 | 原因 | 处理 |
|---|---|---|
| 官网信用卡被拒 | 卡是国内发行、地址不符、银行风控 | 见第 3 节失败表 |
| 第三方校验提示 Team 工作区 | 账号当前在工作区 | 先退出工作区，切回个人空间 |
| 第三方校验提示欠费宽限期 | 之前的官方订阅扣款失败、未结清 | 先在官网结清或取消原订阅 |
| 提示「将覆盖现有会员」 | 账号本来就是 Plus | 确认是要续费或升级再付款 |

### 阶段三：付了钱，账号还是免费版

| 现象 | 原因 | 处理 |
|---|---|---|
| 订单「完成」但账号没变化 | 页面缓存 | 刷新，或退出重新登录 |
| 订单里的邮箱不是你常用的账号 | 浏览器里登录的是另一个账号 | 带订单号联系客服 |
