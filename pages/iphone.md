## 路径一：App Store 内购（海外 Apple ID）

1. 确认手机登录的 Apple ID 是美区等海外地区，且余额够 $19.99 加税。余额用对应地区的礼品卡充，礼品卡一定从正规渠道买，来路不明的卡会导致 Apple ID 被锁。
2. 打开 ChatGPT App，登录你的账号。
3. 点左上角菜单 → 账号 → 「升级到 Plus」。
4. 弹出 Apple 支付确认，面容 ID 确认。
5. 回到 App，立即显示 Plus。

国区 Apple ID 在第 3 步看不到升级按钮，这不是 Bug。切换 Apple ID 地区需要海外付款方式和地址，折腾成本很高，不如走路径二。App 内购和网页订阅的其它差异见 [订阅百科：App 内订阅和网页订阅的区别](https://imi0801.github.io/chatgpt-plus-guide/chatgpt-plus-mobile-app-vs-web/)。

## 常见问题 FAQ

### Q：国区 Apple ID 的 iPhone 能开通 ChatGPT Plus 吗？

能。App 内购入口对国区 Apple ID 不显示，但用 Safari 走网页代充开通后，App 登录同一账号就是 Plus。不需要换 Apple ID。

### Q：App 内购的 $19.99 和官网的 $20 有什么区别？

权益一样。内购由 Apple 收款、按 Apple ID 地区计税、在 Apple 订阅里管理续费和退款；官网由 OpenAI 收款。礼品卡换汇通常还有一层差价。

### Q：iPhone 上开通的 Plus，电脑上能用吗？

能。Plus 绑定账号，电脑网页登录同一账号就是 Plus。

### Q：网页开通后 App 还显示「升级」按钮？

先下拉刷新，再完全退出 App 重开，最后退出登录重登。三步做完还没变，核对订单页邮箱和 App 登录的账号是否一致。

### Q：在 Safari 里复制会话信息只复制了一半？

长按后把选择柄拖到最末尾，或者点「全选」。粘贴后平台校验不通过基本都是没复制完整，重新复制一次即可。

### Q：iPhone 开通的 Plus 怎么续费？

App 内购在设置 → Apple ID → 订阅里管理，Apple 自动续订。网页代充开的不自动扣款，到期前再在平台充一次，详见 [续费说明](https://imi0801.github.io/chatgpt-plus-recharge-guide/renew/)。
