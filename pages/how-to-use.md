## 第一步：注册并登录（3 分钟）

打开 chatgpt.com，点「注册」。**国内用户直接用 163 或 QQ 邮箱注册就行**，不需要专门去弄 Google 账号：

| 方式 | 怎么做 | 说明 |
|---|---|---|
| 国内邮箱注册（推荐） | 填 163 / QQ 邮箱、设密码、去邮箱点验证链接 | 收验证邮件快，手机上就能完成；没有 Gmail 时首选这个 |
| Gmail 注册 | 同上，用 Gmail 地址 | 已经有 Gmail 的可以直接用；也可以点「使用 Google 继续」一键登录 |
| Apple 账号 | 点「使用 Apple 继续」 | 国区 Apple ID 也行；选了「隐藏邮箱」要记下生成的转发地址 |

不建议用 Outlook / Hotmail 这类微软邮箱，也不建议 mail 后缀的小众邮箱：验证邮件经常收不到或进垃圾箱，后续找回账号也麻烦。163 和 QQ 这两个最稳。

注册时如果弹出手机号验证，+86 号码通常不被接受，先换一个邮箱重新注册一次（比如 QQ 换成 163），或者改用 Apple 登录，多数时候就不会再要手机号。手机验证的几种解法、注册后「升级」按钮不出现的原因，在 [ChatGPT 怎么注册](../register/) 里写得很细，这里不重复。

登录成功的标志：进入对话页，左下角显示你的邮箱或名字。先随便发一句「你好」，收到回复就说明账号正常。

## 第二步：认识界面，一分钟看懂

ChatGPT 的页面只有三块，看懂就能用。

**中间的输入框**是一切的起点。打字、回车发送，Shift + 回车换行。输入框左边的「+」或回形针图标用来上传文件和图片，右边的麦克风是语音输入。

**顶部的模型选择**决定「谁来回答」。2026 年的 ChatGPT 统一用 GPT-5 系列，选项分三档：**Instant**（快速，日常问答默认用它）、**Thinking**（先推理再回答，适合数学、代码、复杂分析）、**Pro**（最强档，只有 Pro 订阅能选）。免费账号默认 Instant，系统判断问题复杂时会自动切到 Thinking。选项的具体名字 OpenAI 隔几个月就会改一次，认准「快速 / 思考 / 最强」三档的逻辑就行。

**左侧栏**是历史对话。每次「新对话」都会生成一条记录，点开可以继续聊。侧栏上方还有「搜索对话」「项目」「GPTs」入口，新手前两周用不到，先忽略。

**左下角头像**进设置：改语言、开两步验证、管理记忆、看自己是免费版还是 Plus。

## 第三步：怎么提问，回答质量差一倍

同样的问题，问法不同，回答质量差很多。新手记住四条就够：

1. **说清楚你是谁、要做什么、给谁看。** 「帮我写一封邮件」不如「我是电商运营，帮我写一封给供应商的催货邮件，语气客气但明确要求本周五前发货」。
2. **给材料，别让它猜。** 要改简历就把简历贴进去，要总结文章就把全文贴进去。免费版也支持长文本粘贴。
3. **不满意就接着说，不用重开。** 「太长了，压到 200 字」「换成口语化」「第二点展开讲」，ChatGPT 记得这轮对话的上下文。
4. **复杂任务切到 Thinking。** 算账、写带逻辑的代码、分析一份合同条款，先在模型选择里切到 Thinking 再问，多等十几秒，错误率明显下降。

> [!TIP]
> 一个万能开头：「我要做 ___，目标是 ___，限制条件是 ___，请先列出你打算怎么做，我确认后再开始。」这句话能让 ChatGPT 先对齐思路再动手，省掉大量来回。

## 第四步：电脑和手机怎么装

**电脑**：浏览器打开 chatgpt.com 就是完整版，Chrome 或 Edge 最稳。想要独立窗口可以装官方桌面版（Mac 和 Windows 都有），功能和网页一样。

**iPhone / iPad**：App Store 搜「ChatGPT」，认准 OpenAI 出品。中国区 App Store 没有上架，需要切换到美区或其他地区的 Apple ID 下载。没有海外 Apple ID 的话，用 Safari 打开 chatgpt.com 加到主屏幕，体验接近 App。

**安卓**：Google Play 搜「ChatGPT」，或到 OpenAI 官网下载 APK。国内应用商店里带「ChatGPT」字样的 App 几乎都是套壳，不要装。

**一个账号多端通用**：电脑上注册的账号，手机 App 直接登录，对话历史、记忆、订阅状态全部同步。Plus 开在账号上，不是开在设备上，这一点在 [开通教程总览](../) 里有展开。

## 常见问题 FAQ

### Q：ChatGPT 国内能用吗？

能。账号注册免费，用 163 或 QQ 邮箱就能直接注册，不需要 Google 账号。需要一个能访问 chatgpt.com 的网络环境，这是唯一的硬条件。

### Q：ChatGPT 免费版能用多久？

没有时间限制，免费版可以一直用。限制的是额度：上传、图片生成、Thinking 推理和深度研究都有每天或每几小时的上限，撞到后等一会就恢复。

### Q：ChatGPT 支持中文吗？

完全支持。直接用中文提问，回答也是中文，质量和英文没有明显差别。想要它用英文回答，在问题里加一句「用英文回答」即可。

### Q：ChatGPT 手机 App 在哪里下载？

iPhone 在非中国区 App Store 搜「ChatGPT」，安卓在 Google Play 或 OpenAI 官网下载。中国区 App Store 和国内安卓商店没有官方版本，里面带 ChatGPT 名字的 App 都不是官方的。

### Q：ChatGPT 免费版和 Plus 有什么区别？

免费版功能基本都有，差在次数：Plus 的对话、上传、图片生成、Thinking 额度都高很多，还能用 Codex、创建 GPTs 这类进阶工具，没有广告。每天都用、经常上传文件或写代码的人用 Plus 更顺。

### Q：ChatGPT Go 和 Plus 选哪个？

Go 便宜，额度是免费版的十倍左右，适合每天聊天、翻译、写东西的人。Plus 额度更高，多了 Codex、GPTs 创建等进阶功能，适合写代码、做分析、频繁上传文件的人。

### Q：电脑上注册的账号手机能用吗？

能。ChatGPT 账号多端通用，手机 App 用同一个账号登录，历史对话和订阅状态全部同步。

### Q：免费版用够了怎么升级 Plus？

有海外信用卡可以在官网左下角点「升级」付款；没有的话用支付宝 / 微信在自己账号上代充开通，不需要密码，几分钟到账，步骤见本站 [开通教程总览](../)。
