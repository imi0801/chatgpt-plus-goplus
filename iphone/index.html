在 iPhone 上开通 ChatGPT Plus 有两条路：App 内购，在 ChatGPT App 里点升级，由 Apple 收款；网页开通，用 Safari 打开网页走代充，支付宝 / 微信付款。决定你走哪条的只有一件事：你的 Apple ID 是哪个地区的。国区 Apple ID 在 App 里看不到升级入口，只能走第二条；有美区等海外 Apple ID 且余额充足的，走第一条。两条路开出来的 Plus 完全一样，App 里显示的也一样。

Tip

很多人以为 iPhone 上一定要在 App 里付。其实 Plus 绑定的是 ChatGPT 账号，在 Safari 里开通后，打开 App 刷新就是 Plus。不需要换 Apple ID，也不需要重装 App。

路径一：App Store 内购（海外 Apple ID）

  1. 确认手机登录的 Apple ID 是美区等海外地区，且余额够 $19.99 加税。余额用对应地区的礼品卡充，礼品卡一定从正规渠道买，来路不明的卡会导致 Apple ID 被锁。
  2. 打开 ChatGPT App，登录你的账号。
  3. 点左上角菜单 → 账号 → 「升级到 Plus」。
  4. 弹出 Apple 支付确认，面容 ID 确认。
  5. 回到 App，立即显示 Plus。

国区 Apple ID 在第 3 步看不到升级按钮，这不是 Bug。切换 Apple ID 地区需要海外付款方式和地址，折腾成本很高，不如走路径二。App 内购和网页订阅的其它差异见 订阅百科：App 内订阅和网页订阅的区别。

路径二：Safari 网页开通（支付宝 / 微信）

这条路在 iPhone 上全程用 Safari，不进 App Store。注意两个关键点：用 Safari 而不是微信内置浏览器，以及先在 Safari 里登录 ChatGPT。

1. Safari 登录 ChatGPT

打开 Safari，访问 chatgpt.com，登录你要开通的账号。登录成功后不要关这个标签页。

2. 打开代充平台，选套餐

Safari 新开一个标签页，打开 OKAI66，选 ChatGPT Plus，点「立即充值」。

3. 复制会话信息

Safari 再开一个标签页，地址栏输入 chatgpt.com/api/auth/session。页面显示一段文本，长按 → 全选 → 拷贝。这段文本不含密码。

手机上这一步最常见的问题是只复制了一部分。长按后拖动选择柄到最末尾，或者用「全选」菜单，确认末尾是一个 } 再拷贝。

4. 粘贴、核对、确认订单

切回平台标签页，长按输入框粘贴。系统校验后显示账号邮箱和当前套餐，确认是你的账号。填一个手机号或邮箱用来查订单，点确认。

5. 支付宝 / 微信付款

选支付宝或微信，手机上会直接跳转到对应 App 付款，付完自动回到订单页。在线支付有 2% 通道手续费，加客服微信开通可免。

6. 等自动到账，打开 App 确认

订单页状态「已付款 → 充值中 → 完成」。完成后打开 ChatGPT App，下拉刷新或完全退出 App 再打开，账号页显示 Plus。

Warning

不要在微信内置浏览器里做这套操作。微信内置浏览器的登录状态和 Safari 不互通，会话信息页经常打不开或显示为空。看到朋友转发的链接，点右上角「在 Safari 中打开」再操作。

常见问题 FAQ

Q：国区 Apple ID 的 iPhone 能开通 ChatGPT Plus 吗？

能。App 内购入口对国区 Apple ID 不显示，但用 Safari 走网页代充开通后，App 登录同一账号就是 Plus。不需要换 Apple ID。

Q：App 内购的 $19.99 和官网的 $20 有什么区别？

权益一样。内购由 Apple 收款、按 Apple ID 地区计税、在 Apple 订阅里管理续费和退款；官网由 OpenAI 收款。礼品卡换汇通常还有一层差价。

Q：iPhone 上开通的 Plus，电脑上能用吗？

能。Plus 绑定账号，电脑网页登录同一账号就是 Plus。

Q：网页开通后 App 还显示「升级」按钮？

先下拉刷新，再完全退出 App 重开，最后退出登录重登。三步做完还没变，核对订单页邮箱和 App 登录的账号是否一致。

Q：在 Safari 里复制会话信息只复制了一半？

长按后把选择柄拖到最末尾，或者点「全选」。粘贴后平台校验不通过基本都是没复制完整，重新复制一次即可。

Q：iPhone 开通的 Plus 怎么续费？

App 内购在设置 → Apple ID → 订阅里管理，Apple 自动续订。网页代充开的不自动扣款，到期前再在平台充一次，详见 续费说明。
